# 追溯管理 · 功能规范（spec）

- **模块**：traceability
- **对应页面**：`fluxmes/src/pages/Trace.jsx`
- **依赖**：`specs/constitution.md`
- **版本**：v1.0 · 2026-09-14
- **状态**：Phase 0 已原型实现追溯链可视化；本文档确立工业级产品规格

## 1. 概述（Overview）

追溯管理提供**正向（原料→成品）与逆向（成品→原料）全链路谱系**，是食品安全召回与客诉调查的核心能力（GB 14881、GB 12693 与《食品安全法》对追溯的要求）。原型以 B-260826-007 为例展示从玉米淀粉原料到成品批次的链路节点与物料流转。工业级需补齐：多层级谱系展开、一键影响面分析（某原料批次影响哪些成品）、追溯报表导出、与偏差/报警/检验的横向关联、扫码入口。

## 2. 用户场景（User Scenarios）

- **US1 · 正向追溯**：工艺员输入成品批号 B-260826-007，查看其投用的全部原料批号、各工序设备、操作人、检验结论与入库位。
- **US2 · 逆向追溯（召回）**（工业级）：某玉米淀粉原料批号被供应商通报异常，质检主管输入该原料批号，系统列出所有使用该原料的成品批次及其流向，供召回决策。
- **US3 · 监管/客诉核查**（工业级）：追溯视图需能一键导出 PDF，含关键节点时间戳、参数与检验结论，作为合规证据。
- **US4 · 横向关联**（工业级）：追溯链上某工序曾发生报警或偏差，节点上直接标记并可下钻查看偏差单。
- **US5 · 扫码追溯**（工业级）：扫描成品托盘码直达该批次追溯视图。

## 3. 功能需求（Functional Requirements，EARS）

- **FR-1** WHEN 用户进入追溯页面并输入/选择批次号，THE SYSTEM SHALL 展示该批次的追溯链：原料 → 工序（设备/时间/操作人）→ 检验 → 成品/入库位。
- **FR-2** WHEN 用户点击链路节点，THE SYSTEM SHALL 展示该节点的明细（物料批号、数量、设备、参数快照、检验结论）。
- **FR-3**（工业级）WHEN 用户执行逆向追溯（输入原料批号），THE SYSTEM SHALL 列出所有消耗该原料的成品批次及投用数量与时间。
- **FR-4**（工业级）WHEN 用户请求影响面分析，THE SYSTEM SHALL 汇总受影响成品批次数量、流向与是否已放行，并支持导出清单。
- **FR-5**（工业级）IF 链路节点存在关联报警或偏差单，THE SYSTEM SHALL 在节点上标记并可下钻查看详情。
- **FR-6**（工业级）WHEN 用户点击「导出追溯报表」，THE SYSTEM SHALL 生成可归档文件（PDF/Excel），含 constitution C2 要求的完整字段与生成时间、操作人。
- **FR-7**（工业级）WHEN 用户查询追溯，THE SYSTEM SHALL 记录查询审计（谁在何时查了哪个批次），满足审计要求（C3）。
- **FR-8**（工业级）IF 批次数据不完整（缺原料批号/设备/操作人任一项），THE SYSTEM SHALL 在追溯视图标记「档案不完整」并列出缺失项（C2）。

## 4. 非功能需求（Non-Functional Requirements）

- **NFR-1** 单批次追溯查询响应 < 2s（链路 ≤ 100 节点）。
- **NFR-2** 影响面分析（单原料批次，≤ 500 关联批次）响应 < 5s。
- **NFR-3** 追溯报表导出内容完整、不可缺字段，符合监管核查要求（C2/C6）。
- **NFR-4** 追溯数据留存 ≥ 产品保质期 + 1 年（C6）。

## 5. 边界与约束（Boundaries & Constraints）

- 追溯以**批次**为主键维度，物料粒度到「原料批号」，不做包装级单件追溯（Phase 2 评估）。
- 追溯链一旦生成即只读；数据修正须走偏差流程并保留修正痕迹（C2）。
- 跨企业（供应商→本厂→客户）追溯依赖外部系统数据，本期仅支持已录入的供应商批号。

## 6. 成功标准（Success Criteria）

| # | 验收项 | 判定方式 |
| --- | --- | --- |
| SC-1 | 正向追溯完整 | 输入成品批号可见原料/工序/设备/检验/入库全链路 |
| SC-2 | 逆向追溯准确 | 输入原料批号列出的成品批次与投料记录一致 |
| SC-3 | 影响面可用 | 汇总数量/流向/放行状态正确，可导出 |
| SC-4 | 横向关联 | 节点报警/偏差标记与下钻正常 |
| SC-5 | 档案完整性 | 缺失必填字段的批次被标记并列出缺失项 |
| SC-6 | 查询可审计 | 追溯查询写入审计日志 |

## 7. 依赖与集成点

- **批次管理**：批次档案（原料批号、设备、操作人、计划产量）是追溯链主干。
- **质量管理**：检验结论与 COA 挂接到追溯节点。
- **报警中心 / 偏差**：节点横向关联报警与偏差单。
- **设备管理**：工序设备主数据与校准状态。
