# 质量管理 · 功能规范（spec）

- **模块**：quality-management
- **对应页面**：`src/pages/Quality.jsx`
- **依赖**：`specs/constitution.md`
- **版本**：v1.0 · 2026-08-26
- **状态**：Phase 0 原型已实现 SPC 图/帕累托/检验任务展示；本文档按工业级产品规格补全判异、偏差与放行

## 1. 概述（Overview）

质量管理覆盖流程制造的「过程监控」与「成品放行」：SPC 在线控制图对关键质量特性（如柠檬酸含量）做实时统计过程控制；不合格项帕累托支撑质量改进决策；检验任务管理覆盖成品检验、过程巡检、首件检验，并驱动成品放行。所有判定须标注执行标准（原型引用 **GB 1886.25—2016**）。

## 2. 用户场景（User Scenarios）

- **US1 · 过程监控**：质检员赵敏观察 SPC 控制图，10:30 样本 99.92% 超出 UCL 99.82%，系统标红并提示已触发偏差 DEV-260826-002。
- **US2 · 质量改进**：质量工程师查看近 30 日帕累托，前三项（色度/水分/pH）占 81.1%，据此立项本月专项。
- **US3 · 检验执行**：林晓芸处理 QC-260826-016 首件检验（干燥水分/粒度），2/3 合格，系统提示待复核。
- **US4 · 成品放行**（工业级）：B-260826-009 全项检验完成且合格，质检主管在系统中放行并生成 COA，批次状态转为「待放行/已入库」。
- **US5 · 偏差闭环**（工业级）：SPC 失控或检验不合格触发偏差单，经调查、CAPA、关闭后归档。

## 3. 功能需求（Functional Requirements，EARS）

- **FR-1** WHEN 展示 SPC 控制图，THE SYSTEM SHALL 绘制质量特性时间序列，并叠加 UCL/CL/LCL 三条参考线（值来自标准/过程能力）。
- **FR-2** IF 某样本点超出 UCL 或低于 LCL，THE SYSTEM SHALL 以危险色标记该点并提示已触发偏差单号。
- **FR-3**（工业级）WHEN SPC 数据更新，THE SYSTEM SHALL 按预设判异规则（如 Western Electric / Nelson 规则）自动判异，命中规则列表展示。
- **FR-4** WHEN 展示不合格帕累托，THE SYSTEM SHALL 以条形 + 累计折线呈现各类不合格项次与累计占比。
- **FR-5** WHEN 展示检验任务，THE SYSTEM SHALL 以表格列出任务号、类型、关联批次、检验项目、样本数、合格数、合格率、检验员、状态。
- **FR-6** IF 检验任务合格率低于阈值（如 < 90%），THE SYSTEM SHALL 以警告色标记该任务。
- **FR-7** WHEN 检验任务处于「待复核」，THE SYSTEM SHALL 以脉冲标记并阻断自动放行，须人工复核。
- **FR-8**（工业级）IF 成品全项检验合格且偏差已关闭，THE SYSTEM SHALL 允许质检主管放行并自动生成 COA（检验报告），回流批次档案。
- **FR-9**（工业级）WHEN 触发偏差，THE SYSTEM SHALL 创建偏差单（DEV-xxxx），记录触发源、初步原因、调查与 CAPA，状态机驱动至关闭。
- **FR-10** WHEN 展示任何质量判定，THE SYSTEM SHALL 标注所依据的执行标准及版本（如 GB 1886.25—2016），标准版本变更须留痕（C5）。
- **FR-11**（工业级）WHEN 用户执行放行/复核/偏差关闭，THE SYSTEM SHALL 写审计日志（操作人/时间/结论），满足 C3。

## 4. 非功能需求（Non-Functional Requirements）

- **NFR-1** SPC 图在数据 ≤ 1k 点时渲染流畅，失控点识别实时（≤ 刷新周期）。
- **NFR-2** 判异规则引擎为纯函数，可单元测试（constitution 质量要求）。
- **NFR-3** 帕累托累计计算准确（与原型 `pareto.cum` 口径一致）。
- **NFR-4** COA 生成须可被监管/客户调取，字段符合 GB 1886.25 与交付要求。

## 5. 边界与约束（Boundaries & Constraints）

- SPC 控制限（UCL/CL/LCL）由过程能力研究确定，非固定写死；原型 `SPC_*` 常量在 Phase 1 改为按产品/特性从配置读取。
- 放行是受控动作：未经检验合格 + 偏差关闭，不得放行（状态机在 batch-management 模块）。
- 检验判定逻辑归属 LIMS/质量服务，MES 展示与编排，不直接连仪器。
- 标准版本与产品绑定，切换须审计。

## 6. 成功标准（Acceptance Criteria）

- [ ] SPC 图正确叠加 UCL/CL/LCL，超界点标红并联动偏差单号。
- [ ] 判异引擎命中 Western Electric 规则并列表展示（可测）。
- [ ] 帕累托累计占比计算正确。
- [ ] 检验任务合格率 < 阈值时警告色；待复核脉冲且阻断放行。
- [ ] 成品放行生成 COA 并回流批次；审计记录完整。
