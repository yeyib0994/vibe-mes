# 批次管理 · 任务清单（tasks）

- **模块**：batch-management
- **对应 plan**：`specs/batch-management/plan.md`
- **优先级**：P0 = Phase 1 必须；P1 = 重要；P2 = 增强
- **图例**：✅ 已原型实现

## 任务

### T1 · 台账数据服务化（P0）
- 目标：建立 `src/api/batches.js` 的 `listBatches(filter)` / `getBatch(id)`，Phase 0 返回 Mock。
- 验收：Batches 页面经服务取数；筛选/搜索参数传给服务；Mock 与真实可切换。

### T2 · 服务端分页与搜索索引（P0）
- 目标：实现 FR-1/FR-2/FR-3 的服务端化，单页 ≤ 50 行，关键字覆盖批号/产品/设备/配方。
- 验收：1k 行数据下筛选/搜索 < 300ms；分页计数正确。

### T3 · 批次档案结构化（P0）
- 目标：将 `meta: string[]` 升级为结构化对象（operator/planYield/materialLots/coaNo/warehouseBin/deviationNo）。
- 验收：展开行正确渲染结构化档案；导出字段完整（C2）。

### T4 · 工艺路线带时间戳（P1）
- 目标：stages 由配方版本生成，记录每工序 `startedAt/endedAt`，渲染 done/active/fail/todo。
- 验收：展开工艺路线显示各工序时间；abnormal 批次 fail 工序明显标记（FR-5）。

### T5 · 异常状态机与锁定（P1）
- 目标：实现 `running→waiting→done` 与 `running→abnormal`；abnormal 阻断推进并提示偏差单。
- 验收：异常批次后续工序不可推进；偏差单号可见。

### T6 · 新建批次表单（P1）
- 目标：实现 FR-8，表单校验配方版本 + 原料批号 + 计划产量，提交生成批次号。
- 验收：提交后台账出现新批次（running）；缺必填项阻断提交并提示。

### T7 · 导入生产计划（P1）
- 目标：实现 FR-9，批量创建批次并校验配方/物料一致性。
- 验收：导入文件后批量生成批次；不一致项给出错误清单。

### T8 · 批生产记录页（P1）
- 目标：实现 FR-6，打开全工序电子记录（参数时间序列 + 操作事件 + 检验结论）。
- 验收：点击「批生产记录」进入详情；含工序参数与检验结论。

### T9 · 导出合规归档（P1）
- 目标：实现 FR-7，导出含 C2 全字段的 PDF/Excel。
- 验收：导出文件含配方版本、原料批号、关键参数、操作员、检验、COA、入库位。

### T10 · 审计与放行锁定（P1）
- 目标：实现 FR-10/FR-11，状态变更写审计；done 批次只读锁定。
- 验收：状态变更留 who/when/前后值；已放行批次编辑入口禁用。

### T11 · 正/逆向追溯接入（P2）
- 目标：实现 FR-12，调用 traceability 服务返回正/逆向链路。
- 验收：由成品批号一次操作返回原料批号与全链路。

## 进度总览
- Phase 0 已实现：FR-1~FR-4 展示、FR-6/FR-7 按钮占位。
- Phase 1 关键路径：T1→T2→T3→T5（状态机）→T6/T7（创建/导入）→T8/T9（记录/导出）→T10（审计）。
- Phase 2：T11（追溯）。
