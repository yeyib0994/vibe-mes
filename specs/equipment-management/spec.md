# 设备管理 · 功能规范（spec）

- **模块**：equipment-management（规划中模块，对应章程 §7 的 `equipment-monitor`）
- **对应页面**：`fluxmes/src/pages/Equipment.jsx`
- **依赖**：`specs/constitution.md`
- **版本**：v1.0 · 2026-09-14
- **状态**：Phase 0 已原型实现设备台账与罐区监控卡；本文档确立工业级产品规格

## 1. 概述（Overview）

设备管理维护生产资产的**主数据、实时状态、维护与校准记录**，是批次档案（C2）中「设备」字段的权威来源，也是报警中心的报警源归属对象。原型提供设备台账（编号/名称/型号/位置/状态/运行时长/下次保养）与罐区实时监控卡（温度/压力/液位/搅拌）。工业级需补齐：设备状态机、OEE 计算、维护工单与保养计划、计量校准与有效期、备件关联、与批次的双向追溯。

## 2. 用户场景（User Scenarios）

- **US1 · 值班长巡检罐区**：王强在罐区卡片看到 F-102 发酵罐温度 36.8°C 接近上限，点开查看近 8 小时曲线与关联批次。
- **US2 · 设备台账查询**：工艺员按「运行中」筛选，定位 M-201 配料罐，查看型号、位置、累计运行时长与下次保养日期。
- **US3 · 保养到期处置**（工业级）：系统提示 D-701 流化床干燥机保养逾期 3 天，值班长创建维护工单并排期，期间该设备不可被新批次占用。
- **US4 · 计量校准**（工业级）：质检员登记 E-501 MVR 浓缩器压力变送器的校准结果与有效期；超期未校准则相关工序检验数据标记为「不可用于放行」。
- **US5 · 故障停机**（工业级）：C-601 结晶罐搅拌故障停机，系统自动生成停机事件、扣除可用工时并推送至 OEE 可用性因子。

## 3. 功能需求（Functional Requirements，EARS）

- **FR-1** WHEN 用户进入设备管理，THE SYSTEM SHALL 以表格展示设备台账，列含设备编号、名称、型号、位置、状态、累计运行时长、下次保养日期。
- **FR-2** WHEN 用户按状态（运行/报警/清洗/待机/停机）筛选或输入关键字，THE SYSTEM SHALL 按编号/名称/型号/位置模糊过滤并展示各状态计数。
- **FR-3** WHEN 用户查看罐区/关键设备，THE SYSTEM SHALL 展示其实时工艺参数（温度/压力/液位/搅拌转速等）与近期趋势。
- **FR-4** WHEN 用户展开某设备，THE SYSTEM SHALL 展示该设备的关联报警、在制批次与最近维护记录。
- **FR-5**（工业级）WHEN 设备状态发生变更（运行→停机/清洗/报警），THE SYSTEM SHALL 记录状态事件（起止时间、原因、操作人）并写入审计（C3）。
- **FR-6**（工业级）IF 设备保养日期到期或逾期，THE SYSTEM SHALL 在台账与驾驶舱以醒目状态提示，并允许值班长创建维护工单。
- **FR-7**（工业级）WHEN 维护工单执行完成，THE SYSTEM SHALL 回填维护记录、更新累计运行时长并重算下次保养日期。
- **FR-8**（工业级）WHEN 计量器具校准有效期到期，THE SYSTEM SHALL 标记该设备为「校准超期」，并阻断以其数据作为放行依据的检验结论（C5）。
- **FR-9**（工业级）WHEN 计算设备 OEE，THE SYSTEM SHALL 按「可用率 × 性能率 × 良品率」分解，数据源为设备状态事件、批次产出与质检结论。
- **FR-10**（工业级）WHEN 用户在批次档案中选择设备，THE SYSTEM SHALL 仅列出状态为「可用」且校准在有效期内的设备。

## 4. 非功能需求（Non-Functional Requirements）

- **NFR-1** 设备实时参数刷新 ≤ 30s；关键设备（发酵罐）≤ 10s。
- **NFR-2** 台账在 500 台设备规模下支持服务端分页与索引检索，单页 ≤ 50 行。
- **NFR-3** 状态与报警不得仅以颜色传达，须配文字/图标（C7 可访问性）。
- **NFR-4** 设备状态事件留存 ≥ 3 年，满足食品安全追溯审计要求（C6）。

## 5. 边界与约束（Boundaries & Constraints）

- MES **不做** PLC/DCS 控制逻辑本身（章程 §3 非目标）；控制归 SCADA/PCS，MES 仅采集、存储与展示。
- 设备编号沿用原型风格 `<类别>-<序号>`（如 F-102 发酵罐、E-501 MVR 浓缩器），须全局唯一。
- 设备主数据变更须留痕（版本号 + 操作人 + 时间），历史批次记录引用的是变更时的快照，不得被后续改名影响。

## 6. 成功标准（Success Criteria）

| # | 验收项 | 判定方式 |
| --- | --- | --- |
| SC-1 | 台账展示与筛选 | 5 类状态筛选与关键字检索结果正确，计数一致 |
| SC-2 | 实时参数可见 | 罐区关键参数 ≤ 30s 刷新，趋势图可用 |
| SC-3 | 状态事件可追溯 | 任一状态变更可在审计中查到 who/when/前后值 |
| SC-4 | 保养与校准阻断生效 | 保养逾期设备不可被新批次引用；校准超期设备数据不可用于放行 |
| SC-5 | OEE 口径正确 | 三因子分解结果与手工核算偏差 ≤ 0.5% |

## 7. 依赖与集成点

- **批次管理**：批次档案引用设备编号；设备可用性约束批次建单（FR-10）。
- **报警中心**：报警源归属设备（source 前缀为设备编号），设备台账聚合所属报警。
- **质量管理**：计量校准有效期影响检验结论有效性（C5）。
- **采集层**：OPC-UA / Modbus 采集接入（Phase 2，本期用模拟器）。
